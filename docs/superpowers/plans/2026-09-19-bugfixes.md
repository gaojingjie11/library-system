# 图书系统缺陷修复实施计划

目标：修复审查发现的八项缺陷，验证新 MongoDB 连接；保持现有页面与 API 路径兼容。

设计：Express 统一认证并查询当前有效用户；管理员接口显式鉴权，借阅者从登录身份获取。新库确认为空的 standalone；借阅记录内嵌 book.borrowings，库存与记录通过单文档原子更新同步，无需副本集事务。前端统一 Axios 上传与 API 地址，修正作者字段及归还 ID，并在成功后刷新。

- [x] 数据连接：config/db.js 从被 Git 忽略的 .env 读取凭据；只读 ping、hello、集合结构检查，记录事务能力；文档不存储密码。
- [x] 权限：middleware/auth.js 校验 Bearer JWT 和 del；router/course.js 管理路由限制 admin，普通用户仅访问自己的借阅；userController.js 登录拒绝已删除用户，仅签发用户 ID；usershow 使用白名单 projection。
- [x] 一致性：services/lending.js 使用单文档 $inc + $push/$set 原子更新；扣库存条件 del=0,num>0；归还仅匹配未归还且属于当前用户的记录，管理员可代还；单次写入失败时库存与记录均保持原值。
- [x] 前端：作者查询字段统一 outhor；Table4 使用 _id；Main3/Main4 await 归还成功后刷新和校正页码；AddPop 通过统一 Axios 上传，管理员才可新增。
- [x] 回归：Node 测试覆盖未认证/越权/已删除用户、密码字段投影、作者筛选、并发借阅、失败回滚和重复归还；前端生产构建到临时目录；新库只读连接验证。

验证与范围：不在远程现有数据上执行借阅、删除或重置；不自动修改远程 MongoDB 部署或账号。旧 MinIO 配置改为环境变量；未配置时本地上传存储以完成本地联调。远程服务不启动即建桶。
