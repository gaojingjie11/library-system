# 用户资料、角色管理与 MinIO 图片清理设计

## 目标

为图书管理系统增加管理员角色切换、个人中心和 MinIO 旧图片清理能力，同时保持现有 MongoDB 数据结构和部署方式兼容。

## 已确认的规则

- 用户登录名保持只读，个人中心修改昵称、头像和密码。
- 管理员可以把其他用户设置为管理员或普通用户。
- 管理员不能修改自己的身份。
- 任意角色变更或删除操作后，系统至少保留一个未删除的管理员。
- 头像和图书封面继续保存到 MinIO 公共桶。
- 更新成功后删除旧的、属于当前 MinIO 桶的图片。
- 默认头像 `/avatar.svg` 和不属于当前 MinIO 公共地址的外部图片不删除。

## 方案

采用与现有上传逻辑兼容的分步流程：先上传新图片，再保存资源信息。后端抽取统一的 MinIO 存储服务，负责上传和安全删除；用户头像使用新增的登录用户上传接口，管理员图书封面继续使用现有管理员上传接口。资源更新成功后，控制器根据旧 URL 调用删除服务。

该方案不会让普通用户获得图书封面上传权限，也不改变现有新增图书的上传接口。图片删除只接受能解析为当前 `MINIO_PUBLIC_URL` 下对象的 URL，避免误删任意外部地址。

## 后端接口

### 个人资料

`POST /api/v1/user/avatar`

- 需要登录。
- 接收一个 `file` 图片，沿用现有 5 MB 和 JPG、PNG、WebP、GIF 限制。
- 上传到 MinIO 并返回 `{ url }`，不直接修改数据库。

`PATCH /api/v1/user/profile`

- 需要登录，只修改当前令牌对应的用户。
- 请求 JSON 可包含 `nickname`、`password`、`headImg`。
- `nickname` 非空且长度不超过 30；`password` 沿用现有 6 到 12 个非空白字符规则。
- `headImg` 只能是当前 MinIO 公共地址下的图片 URL，或保留 `/avatar.svg`。
- 保存成功后删除旧头像；没有替换头像时不调用删除。
- 返回更新后的 `name`、`nickname`、`headImg` 和 `identity`。

`GET /api/v1/user/userInfo`

- 增加返回 `nickname`，旧用户没有该字段时回退到 `name`。

### 管理员角色

`PATCH /api/v1/course/useridentity`

- 需要管理员权限。
- 请求 JSON 为 `{ "id": "用户 ObjectId", "identity": "admin" | "user" }`。
- 目标用户不存在时返回 404，角色值非法时返回 400。
- 目标 ID 等于当前管理员 ID 时返回 400。
- 把最后一个管理员降级时返回 409。
- 成功后返回更新后的用户身份。

现有删除用户逻辑增加同样的“至少保留一个管理员”检查，删除最后一个管理员时返回 409。

### 图书封面

现有管理员图书更新接口接受 `course_img`。当封面 URL 改变并且数据库更新成功后，调用同一个 MinIO 删除服务删除旧封面。没有改变封面时不删除。

## MinIO 存储服务

新增集中式存储模块，提供：

- `uploadImage(file)`：生成 UUID 文件名，写入配置的桶并返回公共 URL。
- `deleteManagedImage(url)`：仅解析 `MINIO_PUBLIC_URL` 下的对象键并调用 `removeObject`；非本桶 URL、默认头像和空值直接跳过。

删除失败记录警告但不回滚已经成功的数据库更新，避免因为清理失败导致用户资料或图书更新失败。

## 前端界面

### 个人中心

顶部用户菜单增加“个人中心”，打开新的个人中心视图。表单显示只读登录名，允许编辑昵称、头像、新密码和确认密码。头像通过用户头像上传接口上传，提交后调用资料接口；成功后刷新顶部头像和昵称。

### 用户管理

管理员用户列表增加身份列和身份切换按钮。当前管理员行的切换按钮禁用；最后一个管理员的降级按钮也禁用。服务端仍执行全部保护规则，前端禁用只用于及时提示。角色更新成功后刷新用户列表。

### 图书编辑

管理员编辑图书时增加可选封面替换，沿用管理员上传接口。保存时如果没有选择新图片，保持旧封面；选择新图片并保存成功后由后端清理旧封面。

## 错误处理

- 上传失败、格式不支持或超过 5 MB 时显示后端错误并保留当前表单。
- 角色非法、修改自己身份、删除最后管理员等业务错误显示后端返回的中文提示。
- 资料保存失败时不刷新顶部用户信息。
- MinIO 清理失败只记录服务端警告，不暴露凭据或对象存储内部错误。
